To run the verifier, use the following command structure:

General Command Syntax

Linux/macOS:
  python3 verifier/verifying_consumer.py <queue_or_topic_address> [amqp_url] [vpn_name]
  
  Or use the shell script:
  ./verify_payload.sh <queue_or_topic_address> [amqp_url] [vpn_name]

Windows:
  python verifier\verifying_consumer.py <queue_or_topic_address> [amqp_url] [vpn_name]
  
  Or use the batch script:
  verify_payload.bat <queue_or_topic_address> [amqp_url] [vpn_name]

Execution Examples

1. Using Defaults (from config/test.properties) If you only provide the address, the verifier will use the host,
port, credentials, and VPN defined in your config file.

  Linux/macOS: python3 verifier/verifying_consumer.py "TEST.QUEUE"
  Windows:     python verifier\verifying_consumer.py "TEST.QUEUE"
               OR: verify_payload.bat "TEST.QUEUE"

2. Overriding AMQP URL and VPN If you need to connect to a different broker or use a specific VPN:

  Linux/macOS: python3 verifier/verifying_consumer.py "TEST.QUEUE" "amqp://user:password@host:5672" "MY_VPN_NAME"
  Windows:     python verifier\verifying_consumer.py "TEST.QUEUE" "amqp://user:password@host:5672" "MY_VPN_NAME"
               OR: verify_payload.bat "TEST.QUEUE" "amqp://user:password@host:5672" "MY_VPN_NAME"

3. Listening to a Topic Since the verifier supports topics, you can specify a topic string:

  Linux/macOS: python3 verifier/verifying_consumer.py "my/test/topic"
  Windows:     python verifier\verifying_consumer.py "my/test/topic"
               OR: verify_payload.bat "my/test/topic"

Argument Details

 - <queue_or_topic_address> (Required): The destination address to consume from.
 - [amqp_url] (Optional): The connection string in the format amqp://user:password@host:port.
 - [vpn_name] (Optional): The Solace VPN name (virtual host).

Prerequisites

The verifier requires the python-qpid-proton library:

Linux:
  sudo apt-get install python3-qpid-proton
  OR
  pip3 install python-qpid-proton

Windows:
  pip install python-qpid-proton

The verify_payload.sh (Linux) and verify_payload.bat (Windows) scripts will automatically attempt to install
the required library if it is missing.
